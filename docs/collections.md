# 컬렉션 구성 가이드

이 사이트는 그래픽 포스터, 모션 디자인 정지 스타일 프레임, 컴포지션을 세 개의 탭으로 탐색한다. 모든 컬렉션은 헤더, 페이지 제목, 탭, 카드 캡션, 상세 보기를 공유한다.

## 현재 구성

기존 3D 애니메이션 컬렉션의 20개 스타일은 2026-10-18에 모두 그래픽 포스터 90~109번으로 옮겼다. 기존 포스터 89개와 모션 스타일 프레임 5개는 유지한다. 참고 이미지 두 장에 나온 29개 스타일은 포스터 110~138번으로 추가했다. 중복 스타일도 다른 구도의 새 예시로 유지하며, `reference`에 이미지 파일명과 원본 목록 순서를 기록한다. 디자인 키워드 가이드 `IMG_5062.PNG`의 서로 다른 23개 스타일은 포스터 139~161번으로 추가했다. 같은 이미지에 여러 번 나온 스타일은 키워드를 함께 연결하고, 기존 컬렉션과 겹치는 스타일은 새 구도와 `variantOf`로 추가했다. 추가 참고 자료의 로고 방향 10개와 그래픽 방향 10개는 포스터 162~181번으로 추가했다. 구도 자료는 컴포지션 15개로 분리했다. 표현 기법 참고 스크린샷 7장의 슬릿 스캔·모아레·픽셀 소팅·반투명 유리·점묘·반투명 종이·포인트 클라우드는 포스터 182~188번으로 추가했다. 현재 구성은 **포스터 188개 + 모션 프레임 5개 + 컴포지션 15개 = 총 208개**다.

애니메이션 탭·캔버스·재생 제어·Three.js 의존성은 제거했다. `animation.html`은 예전 공유 주소를 위한 리다이렉트만 담당한다. 렌더러 원본은 Git 이력에 남아 있으며 현재 화면이나 배포에 포함하지 않는다.

## 화면·경로 맵

탭 순서와 기능은 `collections.mjs`의 `COLLECTIONS`가 기준이다. HTML에는 접근 가능한 탭과 패널을 명시하고, 검사 스크립트가 맵과 HTML의 일치를 확인한다.

| 순서 | 키 / 경로 | 탭 | 콘텐츠 / 데이터 | 상세 보기 | 다운로드 |
| --- | --- | --- | --- | --- | --- |
| 1 | `posters` / `#posters` | 포스터 디자인 | `#poster-data.posters` / PNG | `#poster-dialog` | 생성 프롬프트만 |
| 2 | `motion` / `#motion` | 모션 디자인 | `#poster-data.motion` / 정지 스타일 프레임 | `#poster-dialog` | 생성 프롬프트, 모션 이미지·ZIP |
| 3 | `composition` / `#composition` | 컴포지션 | `#poster-data.composition` / 가로 사진 + SVG 구도선 | `#poster-dialog` | 생성 프롬프트만 |

- 빈 해시, `#top`, 이전 `#new-styles` 링크는 포스터 탭을 연다.
- `#posters/188`, `#motion/5`, `#composition/15`는 해당 번호의 상세 보기를 연다. 번호는 항목의 영구 번호이며 정렬된 배열 위치가 아니다. 없는 번호는 해당 컬렉션 목록으로 돌아간다.
- `#animation`과 `animation.html`은 포스터 목록으로 연결한다.
- `#animation/01`, `animation.html#01`은 `#posters/90`으로 연결한다. `collections.mjs`의 `ANIMATION_POSTER_MAP`이 예전 번호와 새 번호의 유일한 경로 기준이다.
- 탭 전환은 방문 기록에 추가한다. 상세 보기와 이전/다음/닫기는 현재 주소를 갱신한다. 브라우저 뒤로/앞으로에서도 선택된 탭과 상세 상태가 주소를 따른다.

## 화면 양식

| 위치 | 공통 규칙 | 컬렉션별로 바꿀 수 있는 것 |
| --- | --- | --- |
| 헤더 | 컬렉션 로고와 보조 문구 | 모션 이미지 ZIP 액션 표시 여부 |
| 소개 | `그래픽 스타일 컬렉션` 제목과 전체 항목 수 | 수량과 소개 문구 |
| 탐색 | 포스터 → 모션 → 컴포지션 순서의 같은 탭 목록 | 새 컬렉션은 기존 탭 뒤에 추가 |
| 목록 상단 | 항목 번호 범위, 최신순 표시 | 정지 스타일 프레임 안내 |
| 카드 | 이미지 → 번호와 한글 제목 → 설명 → 키워드 태그 | 이미지 비율, 포스터만 태그 표시 |
| 상세 보기 | 한글 제목, 작은 영문명, 설명, 키워드, 프롬프트, 이전/다음/닫기 | 모션 연출 설명, 컴포지션 원리·구도선 토글 |
| 푸터 | 공통 집계와 AI 생성 안내, 위로 이동 | 현재 컬렉션의 프롬프트 파일 |

컬렉션 전용 헤더나 별도 화면 골격을 만들지 않는다. 모션 디자인도 현재는 정지 이미지 예시이며, 움직이는 장면으로 안내하지 않는다.

## 제목과 번호 정렬

- 카드와 상세 제목은 `ko`, 상세의 작은 영문명은 `title`을 사용한다. 보통 쓰는 `3D`, `SaaS` 같은 약어는 유지할 수 있다.
- 모든 `.caption`은 `site.css`의 `--caption-font-size`를 사용한다. 번호와 제목 첫 줄의 높이를 같은 값으로 계산하고 위쪽 기준으로 배치한다.
- 번호를 개별 `top`, `transform`, 마진으로 움직이지 않는다. 화면 폭별 크기는 공통 변수로 조정한다.
- 제목이 두 줄이어도 번호는 첫 줄 중앙에 유지한다.
- `number`는 추가 순서다. 카드와 상세 보기 탐색은 모두 번호 내림차순이다.

## 중복 스타일 추가 규칙

같은 스타일이나 겹치는 시각 계열이 다시 요청되면 기존 예시는 유지하고, **다른 레이아웃의 새 예시**를 같은 컬렉션에 추가한다. 중복이라는 이유로 생략·병합·교체하지 않는다. 이 규칙은 앞으로의 추가 작업에 적용하며, 과거에 생략한 항목을 자동으로 재생성하지는 않는다.

- 새 이미지에는 구도, 주요 요소의 배치, 타이포그래피 계층, 여백 중 하나 이상이 명확하게 달라야 한다. 이름·색상·질감만 바꾼 복제는 새 레이아웃으로 보지 않는다.
- 새 `number`, 고유 `slug`와 파일명을 사용한다. 기존 번호와 파일은 보존하고 새 예시는 최신순 목록 앞에 놓는다.
- 데이터의 `variantOf`에는 **같은 컬렉션 안의 기존 항목 번호**를 적는다. 독립된 사조가 생긴 것처럼 설명하지 말고, `description`과 `prompt`에 해당 예시의 구도와 표현을 적는다.
- 이미지 예시는 임베디드 데이터, `prompts.json`, `manifest.json`에 같은 연결을 기록한다. 현재 탭·상세 보기·프롬프트 기능을 그대로 사용한다.
- 새 항목도 수량에 포함해 전체 수, 탭 수, 목록 범위, 메타 설명, 파비콘, 푸터와 README를 함께 갱신한다.

예: 85번 열화상 그래픽은 64번 히트 맵의 인물 중심 레이아웃(`variantOf: 64`), 87번 80년대 멤피스는 50번 멤피스의 패턴 배치 변형(`variantOf: 50`)이다.

## 포스터 키워드 규칙

- 공통 어휘의 유일한 기준은 `collections.mjs`의 `POSTER_TAGS`다. 태그는 사조 이름이 아니라 이미지의 분위기·색감·조형·질감을 설명한다. 현재 25개를 사용한다.
- 모든 포스터의 `tags` 배열에 **서로 다른 한글 키워드 3~5개**를 기록한다. 가장 잘 드러나는 특징을 먼저 적는다. 스타일명이 같아도 밝고 어두운 구도 등 실제 이미지 차이를 확인하고 선택한다.
- `index.html`의 `#poster-data.posters`, `output/poster-styles/prompts.json`의 `styles`, `manifest.json`의 같은 번호에 동일한 배열을 넣는다. 카드와 상세 태그는 `gallery.js`가 이 데이터로 만든다. HTML에 별도 태그 목록을 복사하지 않는다.
- 표기 변형을 늘리지 않는다. ‘컬러풀’은 `컬러풀한`, ‘키치’는 `키치한`, ‘깔끔한(조형)’은 `깔끔한 조형`, ‘깔끔한(구성,타이포)’는 `깔끔한 구성`으로 통일한다. ‘우아한·섬세한’, ‘어두운·암울한’은 각각 독립된 키워드다.
- 스타일을 특정 기분 하나로 고정하는 분류가 아니라 **해당 포스터의 탐색용 해석**이다. 향후 추가할 때도 참고 이미지의 매핑과 실제 생성 결과를 함께 본다.
- 필터는 포스터 탭에만 적용한다. 여러 선택은 **AND**, 선택 해제는 전체 복원이다. `filterByTags`가 조건을 처리하며 원래 번호와 최신순을 유지한다.
- 카드 태그를 누르면 같은 필터가 선택되고 필터 영역으로 이동한다. 상세에서는 읽기 전용 태그를 보여준다. 상세 이전·다음과 카운터는 현재 필터 결과를 따른다.
- 모션 탭을 다녀와도 선택은 유지한다. 새로고침하면 초기화되며 URL에 필터는 저장하지 않는다. 직접 링크의 대상이 필터에서 빠져 있으면 선택을 해제한 뒤 연다. 유효하지 않은 번호는 필터 선택을 바꾸지 않고 목록으로 돌아온다.
- 조건에 맞는 결과가 없을 때는 키워드를 줄이는 안내와 전체 보기 버튼을 제공한다. 태그 버튼은 `aria-pressed`, 결과 수는 라이브 영역으로 알린다. 숨긴 카드는 키보드 탐색에서 제외된다.

추가 양식:

```json
{
  "number": 139,
  "ko": "아르 데코",
  "variantOf": 108,
  "tags": ["세련된", "우아한", "화려한", "기하학적인"]
}
```

키워드 가이드 원본은 사용자 제공 `IMG_5062.PNG`다. 프라서베인의 시각적 특징은 [CARI의 자료](https://www.cari.institute/aesthetics/frasurbane), 미시코 이펙트의 타이포그래피는 [작가의 작업 목록](https://www.behance.net/mishko-co)을 참고했다. 인물·SNS 화면을 옮기지 않고 스타일 이름을 바탕으로 새 포스터를 생성했다.

182~188번은 2026-10-18 23:06~23:07 참고 스크린샷의 표현 기법을 새 포스터로 해석한 예시다. 픽셀 소팅(184)은 글리치(56), 반투명 유리(185)는 프로스티드 글라스(13), 포인트 클라우드(188)는 파티클(90)의 관련 시각 계열로 연결하되 장면과 배치를 새로 만들었다. 벨럼(187)은 이 자료에서 보이는 반투명 종이로 해석하며 유리 재질과 구분한다.

## 컴포지션 추가·구도선 규칙

- 새 탭은 `COLLECTIONS` 마지막에 추가한다. 역할은 `mediaLabel`, `format`, `landscape`, `tags`, `motionNotes`, `guides`, `imageDownload`, `zip`, `numberPrefix`로 명시한다. 미지의 컬렉션을 포스터로 가정하지 않는다. 경로 허용 목록도 이 맵에서 가져온다.
- 컴포지션 번호는 `C01`부터, 영구 주소는 `#composition/1`부터 시작한다. 가로 이미지와 공통 `.landscape-gallery` / `.landscape-view`를 사용한다. 모션 카드와 제목·번호·반응형 규칙을 공유하며 사진 비율만 8:5다.
- `principle`은 구도 사용법, `guide`는 구도선 종류와 장면별 위치다. `composition-guides.mjs`는 1000 × 625 좌표계의 선을 반환하고 `gallery.js`가 이미지의 실제 크기에 맞춰 SVG를 만든다. 이미지 자체에 선을 합성하지 않는다.
- 카드에는 구도선을 표시한다. 상세의 토글은 실제 버튼과 `aria-pressed`를 사용하고, 같은 방문 중 이전·다음에서도 선택을 유지한다. 다른 탭에서는 구도선과 설명을 숨긴다. 선은 장식으로 처리하고 원리는 텍스트로도 제공한다.
- 황금비는 황금 사각형을 반복 분할하고 사분원으로 나선을 근사한다. 구도선은 배치 학습용 가이드이며 사진의 모든 물체가 수학적으로 정확히 일치한다고 설명하지 않는다. 생성된 실제 장면을 보고 `guide.focus` 또는 `guide.paths`를 조정한다.
- 동일한 불꽃 장면을 담은 `IMG_5074.PNG`와 `IMG_5078.PNG`는 C01의 `reference.files`에 함께 기록했다. 삼분할(C04/C08/C10), 대각선(C06/C12), 유도선(C05/C13), 일점 투시·소실점(C02/C14)은 장면이 달라 각각 유지하고 `variantOf`로 연결했다. 제목·선만 있는 자료도 그 원리를 보여주는 새로운 장면으로 제작했다.
- 포스터 162~171은 `IMG_5064.PNG`~`IMG_5073.PNG`의 로고 방향, 172~181은 `IMG_5091.PNG`의 그래픽 목록이다. 바우가즘은 독립된 역사적 사조로 단정하지 않고 [Vasjen Katro의 포스터 프로젝트](https://www.behance.net/katro16)를 참고한 추상 그래픽 예시로 기록했다.

## 새 컬렉션 추가 양식

```text
키 / 경로:
한글 탭 이름:
기존 탭 뒤의 순서:
데이터 위치와 항목 수:
이미지 종류와 카드 비율:
상세 보기에서 필요한 콘텐츠:
다운로드 가능 항목:
기존 링크 호환 방법(있는 경우):
```

1. `COLLECTIONS`와 HTML의 탭/패널 순서·레이블·ARIA 연결을 함께 맞춘다. DOM ID는 유일하게 유지한다.
2. 공통 CSS와 뷰어를 재사용한다. 미디어에만 필요한 차이는 해당 패널/뷰어 범위로 한정한다.
3. 모든 항목에 고유 번호·슬러그·파일을 부여하고, 임베디드 데이터와 프롬프트·매니페스트를 동기화한다.
4. 전체 수, 탭 수, 목록 범위, 메타 설명, 파비콘, 푸터, README 수량을 함께 갱신한다.
5. 새 파일을 `git archive` 배포 대상에 포함하고, 수정한 모듈/CSS 참조의 캐시 버전을 갱신한다.
6. 검증 후 커밋·푸시한다. 배포는 별도 요청이 있을 때만 새 `v*` 태그로 진행한다.

## 검증

```sh
node scripts/check-collections.mjs
node --check gallery.js
node --check collections.mjs
node --check composition-guides.mjs
node --check scripts/check-collections.mjs
git diff --check
```

로컬 브라우저에서 세 탭과 동일한 헤더/제목, 최신순, 한글 제목·번호 정렬을 확인한다. 키보드 좌우/Home/End, 뒤로/앞으로, `#posters/109`·`#motion/5` 직접 링크, `#animation/01`·`animation.html#20` 이전 링크, 상세 닫기·이전·다음·프롬프트를 확인한다. 좁은 화면의 잘림과 가로 스크롤도 검사한다. 키워드 단일·복수 선택, 선택 해제, 결과 없음, 카드 태그 클릭, 필터 안의 이전·다음, 필터에서 제외된 번호의 직접 링크, 탭을 다녀온 뒤 선택 유지도 확인한다.

포스터 다운로드가 다시 생기지 않았는지, 모션 이미지 다운로드와 프롬프트가 현재 탭에 맞는지 확인한다. 예전 애니메이션 탭, 재생 제어, 캔버스나 Three.js 요청이 남지 않아야 한다. 화면 캡처는 `output/*preview*.png`처럼 Git에서 제외되는 경로에 저장한다.

컴포지션 검증 시 `#composition/15` 직접 진입, 구도선 토글·키보드 작동, 이전·다음의 토글 유지, 다른 탭으로 이동 후 구도선 제거, 가로 이미지와 SVG 정렬을 데스크톱·좁은 화면에서 함께 확인한다.
