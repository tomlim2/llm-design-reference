# 컬렉션 구성 가이드

이 사이트는 하나의 디자인 스타일 컬렉션을 세 개의 탭으로 탐색한다. 콘텐츠 종류가 달라도 헤더, 페이지 제목, 탭, 카드 캡션, 상세 보기의 시각 규칙은 같다.

## 통합한 이유

3D 애니메이션이 별도 `animation.html` 페이지와 헤더 링크로 추가되면서 기존의 포스터/모션 탭 흐름과 분리됐다. 페이지 CSS도 복사되어 한글 제목과 번호 정렬 수정이 한쪽에만 반영됐다. 이를 해결하기 위해 화면 골격과 공통 CSS를 한 곳으로 모으고, 3D 렌더러는 탭 안의 콘텐츠로만 동작하게 했다.

## 화면·경로 맵

탭 순서와 기능의 기준은 `collections.mjs`의 `COLLECTIONS`다. HTML에는 접근 가능한 탭과 패널을 명시하고, 검사 스크립트가 맵과 HTML의 일치를 확인한다.

| 순서 | 키 / 경로 | 탭 | 콘텐츠 / 데이터 | 상세 보기 | 다운로드 |
| --- | --- | --- | --- | --- | --- |
| 1 | `posters` / `#posters` | 포스터 디자인 | `#poster-data.posters` / PNG | `#poster-dialog` | 생성 프롬프트만 |
| 2 | `motion` / `#motion` | 모션 디자인 | `#poster-data.motion` / 정지 스타일 프레임 | `#poster-dialog` | 생성 프롬프트, 모션 이미지·ZIP |
| 3 | `animation` / `#animation` | 3D 애니메이션 | `#animation-data.styles` / 실시간 장면 | `#animation-dialog` | 생성 프롬프트만 |

- 빈 해시, `#top`, 이전 `#new-styles` 링크는 포스터 탭을 연다.
- `#animation/20`은 3D 탭의 20번 상세 보기를 연다. 번호는 항목의 영구 번호이며, 정렬된 배열 위치가 아니다.
- 이전 `animation.html` 및 `animation.html#01` 링크는 통합 화면으로 리다이렉트한다. 이 파일에는 새 UI를 만들지 않는다.
- 탭 클릭은 브라우저 방문 기록에 남는다. 상세 보기 이동/닫기는 현재 3D 경로를 갱신한다.

## 화면 양식

| 위치 | 공통 규칙 | 컬렉션별로 바꿀 수 있는 것 |
| --- | --- | --- |
| 헤더 | 컬렉션 로고, 보조 문구 유지 | 기존 모션 이미지 ZIP 액션의 표시 여부 |
| 소개 | `디자인 스타일 컬렉션` 제목과 전체 항목 수 | 컬렉션 추가 시 전체 수와 소개 문구 갱신 |
| 탐색 | 포스터 → 모션 → 3D의 같은 탭 목록 | 새 컬렉션은 기존 탭 뒤에 추가 |
| 목록 상단 | 항목 번호 범위, 최신순 표시 | 정지 프레임/실시간 여부, 해당 패널 안의 재생 제어 |
| 카드 | 이미지/캔버스 → 번호와 한글 제목 → 설명 | 미디어 비율과 재생 동작 |
| 상세 보기 | 한글 제목, 작은 영문명, 설명, 프롬프트, 이전/다음/닫기 | 모션 연출 설명, 3D 재생·재시작 제어 |
| 푸터 | 공통 집계와 출처 성격, 위로 이동 | 현재 컬렉션의 프롬프트 파일 |

3D 전용 제목이나 내비게이션을 헤더에 추가하지 않는다. Three.js 버전, WebGL 버전 같은 구현 정보는 문서에 적고, 화면에는 사용자가 선택하는 데 필요한 정보만 표시한다.

## 파일 역할 맵

| 파일 | 책임 | 여기서 하지 않는 일 |
| --- | --- | --- |
| `index.html` | 유일한 화면 골격, 탭/패널, 이미지 카드, 두 뷰어, 임베디드 데이터 | 컬렉션별 독립 헤더/푸터 |
| `site.css` | 색상, 서체, 간격, 헤더, 탭, 그리드, 번호 정렬, 뷰어, 반응형 규칙 | 개별 3D 장면 효과 |
| `animation.css` | `#animation-panel`, `#animation-dialog` 아래 캔버스·재생 제어 스타일 | 전역 `h1`, `.caption`, `.number`, 헤더 덮어쓰기 |
| `collections.mjs` | 탭 순서/키/레이블/기능 맵, 최신순 정렬, 경로 해석 | DOM 조작, WebGL 렌더링 |
| `gallery.js` | 모든 탭 전환, URL, 푸터 액션, 이미지 뷰어, 3D 지연 로딩 | 3D 장면 구현 |
| `animation.mjs` | 3D 카드/뷰어, 재생 상태, 렌더링 수명 관리 | 공통 헤더/탭/푸터/URL 직접 변경 |
| `animation-styles.mjs` | 스타일별 Three.js 장면 `build()` | 사이트 탐색과 공통 UI |
| `animation.html` | 이전 링크 호환 리다이렉트 | 독립 갤러리 |
| `output/*/prompts.json`, `manifest.json` | 이미지 생성 기록과 파일 정보 | 화면 UI 상태 |
| `scripts/check-collections.mjs` | 탭·패널·데이터·배포 파일의 구조 검증 | 실제 렌더링의 시각 검증 대체 |
| `.github/workflows/deploy.yml` | `v*` 태그로 정적 파일 배포 | 일반 브랜치 푸시로 배포 |

## 제목과 번호 정렬

- 카드와 상세 제목은 `ko`, 상세의 작은 영문명은 `title`을 사용한다. 보통 쓰는 `3D`, `SaaS` 같은 약어는 유지할 수 있다.
- 모든 `.caption`은 `site.css`의 `--caption-font-size`를 사용한다. 번호와 제목의 첫 줄 높이를 같은 값으로 계산하고 위쪽 기준으로 배치한다.
- 번호를 임의의 `top`, `transform`, 개별 마진으로 움직이지 않는다. 화면 폭별 크기를 바꿀 때는 해당 변수를 조정한다.
- 제목이 두 줄이어도 번호는 첫 줄 중앙에 유지한다.
- 항목의 `number`는 추가 순서를 나타낸다. 카드와 상세 보기 탐색은 모두 번호 내림차순이다.

## 3D 수명 관리

`gallery.js`가 3D 탭을 처음 열 때만 `animation.mjs`를 불러온다. 렌더러는 `initializeAnimationGallery({ styles, onSelect, onClose })`로 한 번 초기화한다.

| 메서드 | 동작 |
| --- | --- |
| `setActive(true)` | 현재 크기 반영, 보이는 카드 렌더링 재개 |
| `setActive(false)` | 상세 닫기, 프레임 루프 취소, 카드의 장면 자원 해제 |
| `openStyle(number)` | 영구 번호로 상세 열기. 유효하지 않거나 `null`이면 닫기 |
| `close()` | 상세 보기 닫기 |

백그라운드 브라우저 탭에서도 프레임 루프를 멈춘다. 늦게 끝난 로딩이 이미 떠난 컬렉션을 활성화하지 않도록 현재 선택을 확인한다. CDN 또는 WebGL 실패 시 설명과 프롬프트를 볼 수 있게 한다. Three.js r160과 외부 폰트를 CDN에서 불러오므로 최초 3D 사용에는 인터넷이 필요하다.

## 새 컬렉션 추가 양식

작업 전에 아래 항목을 정하고 같은 파일 맵을 따른다.

```text
키 / 경로:
한글 탭 이름:
기존 탭 뒤의 순서:
데이터 위치와 항목 수:
미디어 종류와 카드 비율:
상세 보기에서 필요한 콘텐츠:
다운로드 가능 항목:
활성/비활성 때 필요한 작업:
기존 링크 호환 방법(있는 경우):
```

1. `COLLECTIONS`에 정의하고 `index.html`에 같은 순서의 `role="tab"`, `role="tabpanel"`을 연결한다. `id`, `aria-controls`, `aria-labelledby`는 서로 맞아야 한다.
2. 모든 DOM ID를 유일하게 만든다. 전용 뷰어 ID에는 컬렉션 접두어를 붙인다.
3. 공통 CSS를 재사용한다. 미디어에만 필요한 규칙은 패널/뷰어 범위로 한정한다.
4. 제목의 전체 수, 탭 수, 목록 범위, 메타 설명, 파비콘, 푸터, README 수량을 함께 갱신한다.
5. 정적 배포에 필요한 새 파일은 `git archive` 대상에 포함한다. 수정된 모듈/CSS 참조에는 새 캐시 버전을 사용한다.
6. 아래 검증을 마친 뒤 커밋·푸시한다. 배포는 별도 요청이 있을 때만 새 `v*` 태그로 진행한다.

## 검증

```sh
node scripts/check-collections.mjs
node --check gallery.js
node --check collections.mjs
node --check animation.mjs
node --check animation-styles.mjs
git diff --check
```

로컬 브라우저에서 세 탭의 순서와 동일한 헤더/제목, 한글 제목 및 번호 정렬을 확인한다. 키보드 좌우/Home/End와 선택 상태, 브라우저 뒤로/앞으로, 직접 `#animation`/상세 링크/이전 링크, 상세의 닫기·이전·다음·프롬프트, 다른 탭으로 이동할 때의 3D 정지를 확인한다. 좁은 화면에서 탭과 제목이 잘리거나 본문에 가로 스크롤이 생기지 않는지도 확인한다.

포스터 다운로드가 다시 생기지 않았는지, 모션 이미지 다운로드와 프롬프트가 현재 탭에 맞는지도 확인한다. 화면 캡처는 `output/*preview*.png`처럼 Git에서 제외되는 경로에 저장한다.
