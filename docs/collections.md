# 컬렉션 구성 가이드

이 사이트는 그래픽 포스터와 모션 디자인 정지 스타일 프레임을 두 개의 탭으로 탐색한다. 두 컬렉션은 헤더, 페이지 제목, 탭, 카드 캡션, 상세 보기를 공유한다.

## 현재 구성

기존 3D 애니메이션 컬렉션의 20개 스타일은 2026-10-18에 모두 그래픽 포스터 90~109번으로 옮겼다. 기존 포스터 89개와 모션 스타일 프레임 5개는 유지한다. 현재 구성은 **포스터 109개 + 모션 프레임 5개 = 총 114개**다.

애니메이션 탭·캔버스·재생 제어·Three.js 의존성은 제거했다. `animation.html`은 예전 공유 주소를 위한 리다이렉트만 담당한다. 렌더러 원본은 Git 이력에 남아 있으며 현재 화면이나 배포에 포함하지 않는다.

## 화면·경로 맵

탭 순서와 기능은 `collections.mjs`의 `COLLECTIONS`가 기준이다. HTML에는 접근 가능한 탭과 패널을 명시하고, 검사 스크립트가 맵과 HTML의 일치를 확인한다.

| 순서 | 키 / 경로 | 탭 | 콘텐츠 / 데이터 | 상세 보기 | 다운로드 |
| --- | --- | --- | --- | --- | --- |
| 1 | `posters` / `#posters` | 포스터 디자인 | `#poster-data.posters` / PNG | `#poster-dialog` | 생성 프롬프트만 |
| 2 | `motion` / `#motion` | 모션 디자인 | `#poster-data.motion` / 정지 스타일 프레임 | `#poster-dialog` | 생성 프롬프트, 모션 이미지·ZIP |

- 빈 해시, `#top`, 이전 `#new-styles` 링크는 포스터 탭을 연다.
- `#posters/109`, `#motion/5`는 해당 번호의 상세 보기를 연다. 번호는 항목의 영구 번호이며 정렬된 배열 위치가 아니다. 없는 번호는 해당 컬렉션 목록으로 돌아간다.
- `#animation`과 `animation.html`은 포스터 목록으로 연결한다.
- `#animation/01`, `animation.html#01`은 `#posters/90`으로 연결한다. `collections.mjs`의 `ANIMATION_POSTER_MAP`이 예전 번호와 새 번호의 유일한 경로 기준이다.
- 탭 전환은 방문 기록에 추가한다. 상세 보기와 이전/다음/닫기는 현재 주소를 갱신한다. 브라우저 뒤로/앞으로에서도 선택된 탭과 상세 상태가 주소를 따른다.

## 화면 양식

| 위치 | 공통 규칙 | 컬렉션별로 바꿀 수 있는 것 |
| --- | --- | --- |
| 헤더 | 컬렉션 로고와 보조 문구 | 모션 이미지 ZIP 액션 표시 여부 |
| 소개 | `그래픽 스타일 컬렉션` 제목과 전체 항목 수 | 수량과 소개 문구 |
| 탐색 | 포스터 → 모션 순서의 같은 탭 목록 | 새 컬렉션은 기존 탭 뒤에 추가 |
| 목록 상단 | 항목 번호 범위, 최신순 표시 | 정지 스타일 프레임 안내 |
| 카드 | 이미지 → 번호와 한글 제목 → 설명 | 이미지 비율 |
| 상세 보기 | 한글 제목, 작은 영문명, 설명, 프롬프트, 이전/다음/닫기 | 모션 연출 설명 |
| 푸터 | 공통 집계와 AI 생성 안내, 위로 이동 | 현재 컬렉션의 프롬프트 파일 |

컬렉션 전용 헤더나 별도 화면 골격을 만들지 않는다. 모션 디자인도 현재는 정지 이미지 예시이며, 움직이는 장면으로 안내하지 않는다.

## 제목과 번호 정렬

- 카드와 상세 제목은 `ko`, 상세의 작은 영문명은 `title`을 사용한다. 보통 쓰는 `3D`, `SaaS` 같은 약어는 유지할 수 있다.
- 모든 `.caption`은 `site.css`의 `--caption-font-size`를 사용한다. 번호와 제목 첫 줄의 높이를 같은 값으로 계산하고 위쪽 기준으로 배치한다.
- 번호를 개별 `top`, `transform`, 마진으로 움직이지 않는다. 화면 폭별 크기는 공통 변수로 조정한다.
- 제목이 두 줄이어도 번호는 첫 줄 중앙에 유지한다.
- `number`는 추가 순서다. 카드와 상세 보기 탐색은 모두 번호 내림차순이다.

## 중복 스타일 추가 규칙

같은 스타일이나 겹치는 시각 계열이 다시 요청되면 기존 예시는 유지하고, **다른 레이아웃의 새 예시**를 같은 컬렉션에 추가한다. 중복이라는 이유로 생략·병합·교체하지 않는다. 이 규칙은 앞으로의 추가 작업에 적용하며, 과거에 생략한 항목을 자동으로 재생성하지는 않는다.

- 새 이미지에는 구도, 주요 요소의 배치, 타이포그래피 계층, 여백 중 하나 이상이 명확하게 달라야 한다. 이름·색상·질감만 바꾼 복제는 새 레이아웃으로 보지 않는다.
- 새 `number`, 고유 `slug`와 파일명을 사용한다. 기존 번호와 파일은 보존하고 새 예시는 최신순 목록 앞에 놓는다.
- 데이터의 `variantOf`에는 **같은 컬렉션 안의 기존 항목 번호**를 적는다. 독립된 사조가 생긴 것처럼 설명하지 말고, `description`과 `prompt`에 해당 예시의 구도와 표현을 적는다.
- 이미지 예시는 임베디드 데이터, `prompts.json`, `manifest.json`에 같은 연결을 기록한다. 현재 탭·상세 보기·프롬프트 기능을 그대로 사용한다.
- 새 항목도 수량에 포함해 전체 수, 탭 수, 목록 범위, 메타 설명, 파비콘, 푸터와 README를 함께 갱신한다.

예: 85번 열화상 그래픽은 64번 히트 맵의 인물 중심 레이아웃(`variantOf: 64`), 87번 80년대 멤피스는 50번 멤피스의 패턴 배치 변형(`variantOf: 50`)이다.

## 애니메이션에서 포스터로 옮긴 항목

각 새 포스터의 `migratedFrom`에는 이전 컬렉션 키·번호·슬러그를 기록한다. `variantOf`는 같은 포스터 컬렉션 안에서 기존 스타일과 연결할 때 별도로 사용한다. 정지 포스터의 설명·프롬프트에는 재생 방법이나 렌더러 코드 대신 해당 이미지의 구도와 표현을 적는다.

## 새 컬렉션 추가 양식

```text
키 / 경로:
한글 탭 이름:
기존 탭 뒤의 순서:
데이터 위치와 항목 수:
이미지 종류와 카드 비율:
상세 보기에서 필요한 콘텐츠:
다운로드 가능 항목:
기존 링크 호환 방법(있는 경우):
```

1. `COLLECTIONS`와 HTML의 탭/패널 순서·레이블·ARIA 연결을 함께 맞춘다. DOM ID는 유일하게 유지한다.
2. 공통 CSS와 뷰어를 재사용한다. 미디어에만 필요한 차이는 해당 패널/뷰어 범위로 한정한다.
3. 모든 항목에 고유 번호·슬러그·파일을 부여하고, 임베디드 데이터와 프롬프트·매니페스트를 동기화한다.
4. 전체 수, 탭 수, 목록 범위, 메타 설명, 파비콘, 푸터, README 수량을 함께 갱신한다.
5. 새 파일을 `git archive` 배포 대상에 포함하고, 수정한 모듈/CSS 참조의 캐시 버전을 갱신한다.
6. 검증 후 커밋·푸시한다. 배포는 별도 요청이 있을 때만 새 `v*` 태그로 진행한다.

## 검증

```sh
node scripts/check-collections.mjs
node --check gallery.js
node --check collections.mjs
node --check scripts/check-collections.mjs
git diff --check
```

로컬 브라우저에서 두 탭과 동일한 헤더/제목, 최신순, 한글 제목·번호 정렬을 확인한다. 키보드 좌우/Home/End, 뒤로/앞으로, `#posters/109`·`#motion/5` 직접 링크, `#animation/01`·`animation.html#20` 이전 링크, 상세 닫기·이전·다음·프롬프트를 확인한다. 좁은 화면의 잘림과 가로 스크롤도 검사한다.

포스터 다운로드가 다시 생기지 않았는지, 모션 이미지 다운로드와 프롬프트가 현재 탭에 맞는지 확인한다. 예전 애니메이션 탭, 재생 제어, 캔버스나 Three.js 요청이 남지 않아야 한다. 화면 캡처는 `output/*preview*.png`처럼 Git에서 제외되는 경로에 저장한다.
